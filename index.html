🤔 What is retrocommit?

retrocommit is a small program that runs on your computer. It helps you fill in missing days on your GitHub contribution graph — the little green squares that show your coding activity. Instead of manually creating commits, you can use retrocommit to add them automatically, right from your terminal (the command prompt on Windows). It's designed for people who want a complete-looking contribution history without complex setup.

Whether you're a student, a hobbyist, or a professional developer, retrocommit makes it easy to keep your GitHub profile looking active and consistent.

🛠️ How to Use retrocommit

Using retrocommit is as simple as typing one command. Here's your first-time guide:

  1. Open your terminal: Press the Windows key, type "Command Prompt" or "PowerShell", and press Enter.
  2. Check Git (optional but helpful): Type git --version and press Enter. If you see a version number, Git is installed. If not, visit git-scm.com to install it first.
  3. Run retrocommit: In the terminal, type retrocommit and press Enter.
  4. Follow the prompts: retrocommit will ask you a few simple questions, like which dates to fill and how many commits to add. Just answer them.
  5. Done! After a few seconds, your contribution graph will be updated. Check your GitHub profile to see the changes.

That's it! No complex commands, no coding knowledge needed.

❓ Frequently Asked Questions

Is retrocommit safe to use?

Yes. retrocommit only creates Git commits on your local machine. It doesn't modify your GitHub account settings or personal data. It's built with standard, safe programming practices.

Will this break my GitHub account?

No. It simply adds commits to your local repository, which you can then push to GitHub if you want. It's the same as making commits manually, just automated.

No, retrocommit is completely free to download and use.

What if I get an error?
